# Mèo Xinh 222

Game "phòng kín" phá án, nhưng **bạn là hung thủ**. Bạn là **Mèo Xinh**: ăn vụng cá trên bàn,
rồi bày lại hiện trường để bà Hằng về nhà và hét lên **"LỘC!!!"** (con chó vô tội).
Nhẹ nhàng, vui. Hiện có một màn: ngày thứ Hai trong căn bếp.

*A cozy "reverse locked-room" game: you are the cat who stole the fish, and you frame the dog.
Made with Godot 4.7.2, playable in the browser. The game text is in Vietnamese; code and comments are in English.*

## Chơi ngay

https://dltronganh.github.io/cat-cute-game/ (chơi trên máy tính, bằng bàn phím và chuột).

## Điều khiển

| Phím | Việc |
|---|---|
| W A S D hoặc phím mũi tên | Đi |
| Space | Nhảy |
| E hoặc Enter | Hành động |
| Q / R | Xoay camera |
| P | Tạm dừng |
| Esc | Chơi lại |

Đổi bộ lông cho Mèo Xinh và chỉnh âm lượng bằng chuột, ở màn hình bắt đầu hoặc khi tạm dừng.

## Mở trên máy

1. Tải [Godot 4.7.2](https://godotengine.org/download) (bản thường, không cần bản .NET).
2. Tải repo này về (nút **Code → Download ZIP**, hoặc `git clone`).
3. Mở Godot, chọn **Import**, trỏ tới file `project.godot`, rồi bấm **Run** (F5).
